# Amsal Nizamuddin — Portfolio

A minimal, editorial portfolio site built with **Next.js**, **Tailwind CSS**, and **Supabase**. Designed to deploy on **Vercel** in under 10 minutes.

## Stack

- **Next.js 14** — React framework with App Router
- **Tailwind CSS** — utility-first styling
- **Supabase** — stores contact form submissions
- **GitHub** — version control
- **Vercel** — hosting & auto-deploys

---

## Quick start (local)

```bash
# 1. Install dependencies
npm install

# 2. Copy the env example file and fill in your Supabase keys
cp .env.local.example .env.local

# 3. Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## Step 1 — Set up Supabase

1. Go to [supabase.com](https://supabase.com) and create a free account.
2. Create a new project. Pick any name and password (save the password).
3. Once the project is ready, go to **SQL Editor** (left sidebar) and run this:

```sql
create table contact_messages (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now(),
  name text not null,
  email text not null,
  message text not null
);

-- Allow anyone to INSERT (for the contact form) but not read.
alter table contact_messages enable row level security;

create policy "Anyone can submit a contact message"
  on contact_messages for insert
  to anon
  with check (true);
```

4. Go to **Settings → API** and copy:
   - **Project URL** → `NEXT_PUBLIC_SUPABASE_URL`
   - **anon public** key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. Paste them into your `.env.local` file.

You'll read submissions in Supabase under **Table Editor → contact_messages**.

## Step 2 — Push to GitHub

```bash
git init
git add .
git commit -m "Initial portfolio"

# Create a new repo on github.com first (e.g. "amsal-portfolio"), then:
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/amsal-portfolio.git
git push -u origin main
```

---

## Step 3 — Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and sign in with your GitHub account.
2. Click **Add New → Project**.
3. Import your `amsal-portfolio` repo.
4. **Important:** under **Environment Variables**, add the same two keys from `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. Click **Deploy**.

Done. Every time you `git push`, Vercel auto-deploys.

## Customizing

- **Resume content** — edit `components/Experience.tsx` and `components/Projects.tsx`.
- **Bio** — edit `components/Hero.tsx` and `components/About.tsx`.
- **Contact info** — edit `components/Contact.tsx` (LinkedIn URL, etc.).
- **Colors / fonts** — edit `tailwind.config.js` and `app/globals.css`.

## Custom domain

In Vercel: **Project → Settings → Domains → Add**. Vercel walks you through pointing your DNS.
